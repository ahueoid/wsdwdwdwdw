# Documentar o fluxo de contribuição e validação

## Fluxo de contribuição

1. Descreva o problema e o resultado esperado antes de alterar o código.
2. Crie uma branch a partir da branch padrão atualizada.
3. Implemente a mudança e execute os testes relevantes.
4. Abra um pull request com a descrição da mudança e as evidências de validação.
5. Confira os checks e as regras do repositório antes do merge.
6. Após o merge, verifique se o comportamento esperado foi publicado.
